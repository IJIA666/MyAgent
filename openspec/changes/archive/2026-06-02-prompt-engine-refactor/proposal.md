## 改造原因

当前的 `SessionManager` 中，将大模型的核心“人设”提示词（System Prompt）以大段字符串长文本的形式硬编码在了业务逻辑代码（`src/brain/session.ts`）内部。这不仅造成代码臃肿、阻碍可读性，更重要的是，在未来我们需要扩展“动态挂载不同人设”、“注入环境上下文”时会导致修改成本极高。
当前业务体量尚未达到需要引入类似 Hermes-Agent 那样庞大的 3 层上下文引擎（基础态、上下文态、易失态）的阶段。因此，我们需要进行一次**克制版降级重构**，仅仅将静态文本外置并预留出 `Builder` 构建接口，为未来的扩展预留合理的架构锚点。

## 变更内容

- 移除 `src/brain/session.ts` 内部硬编码的大段 System Prompt 字符串。
- 将提示词文本外挂至独立的管理文件（例如 `src/brain/prompts.ts` 或配置文件中）。
- 新增轻量级的基础 `PromptBuilder` 类或工厂函数，目前仅负责静态文本的返回与输出，从而在调用链路上隔绝耦合。
- `SessionManager` 初始化时改由从 `PromptBuilder` 索取系统级预设提示词。

## 业务能力

### 新增业务能力
- `prompt-engine`: 建立提示词文本物理管理与逻辑构建的基础防腐层抽象。

### 修改业务能力
无

## 影响范围

- **受影响模块**：重构范围仅限于 `src/brain/session.ts` 以及新增的 `prompt-engine` 相关结构。
- **外部影响**：这是一个纯粹的重构动作，对 `interface` 路由和 `action` 调度层完全透明，不影响系统现有的运行逻辑与输入输出。
