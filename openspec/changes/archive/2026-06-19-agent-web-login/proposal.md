## 改造原因

当前的智能体（IJIA Agent）是一个基于命令行终端的极简 Agent，缺乏对外部网页的可视化交互与状态登录能力。为了拓展智能体的业务执行边界（例如自动登录各种办公网站、代替用户执行常规的网页表单处理、截图核验等任务），需要为智能体引入底层浏览器自动化控制与会话管理引擎。

我们需要建立一套既能抵御复杂登录风控（如滑块、扫码），又能自动持久化会话（Session/Cookie），同时具备环境兼容性与用户隔离安全的浏览器操作方案。

## 变更内容

本次变更将在智能体中集成 Playwright 浏览器驱动，并实现以下三大核心变动：
1. **双通道登录与会话共享**：内置支持 `chromium.connectOverCDP`（直接连接用户物理隔离的 Chrome 调试端口，共享已有登录态）和 `launchPersistentContext`（使用本地持久化 Session 目录自动保存 Cookies），确保智能体能跨会话免重复登录。
2. **交互式风控阻塞与人机协作**：当智能体首次登录或面临无法自动破解的人机验证（滑块、短信、扫码）时，支持在命令行终端暂停智能体推理，自动启动有头浏览器，提示并等待用户手动在弹窗中辅助完成验证，输入回车后智能体同步状态继续执行。
3. **极简 DOM 标号快照（AriaSnapshot 机制）**：将复杂的网页 HTML 结构过滤精简，仅把可交互的按钮、输入框标注为 `@e1`、`@e2` 等编号快照提供给 LLM，大模型仅需通过编号即可精准操作网页，解决冗余 HTML 撑爆 Token 及定位不准的问题。

## 业务能力

### 新增业务能力

- `web-automation`: 提供智能体以人机协作或全自动方式登录目标网站，并控制浏览器进行网页表单填写、点击、滚动、截图等通用网页操作的能力。

### 修改业务能力

无。

## 影响范围

1. **依赖项变化**：
   - 需在 `package.json` 中引入 `playwright`（及可能的 `playwright-extra`/`stealth` 插件）。
2. **工具链体系（Action）**：
   - 在 `src/action/native-tools` 目录下新增 `browser-action` 工具类，提供网页控制 API。
   - 修改 `src/action/toolRegistry.ts` 将内置的浏览器 Native Tools 注册挂载。
3. **会话管理（Brain）**：
   - 修改 `src/brain/index.ts` 中的会话管理器，新增协调智能体在人机验证登录时执行阻塞等待的逻辑。
4. **终端界面（Interface）**：
   - 修改 `src/interface/` 交互层，新增支持提示用户手动干预、暂停推理并接收回车激活的阻塞指令通道。
