# 提案: 长期记忆双路混合检索与 RRF 重排融合

## 核心目标与背景
系统当前的长期记忆组件通过向量（语义）检索对历史背景和事实做到了出色的泛化召回。然而，在以代码研发为核心的智能体交互场景下，用户经常输入包含高精度的 API 名称（如 `SessionManager`）、物理文件名（如 `session.ts`）等关键短语。由于向量空间特有的语义泛化问题，纯向量检索对此类精准的技术标识符极易漏匹配。
本提案旨在通过在 `LongTermMemoryPlugin` 拦截插件中，融合向量检索（语义模糊）与直接读取物理 facts 的正则表达式多级级联匹配（精准物理），并通过倒数排名融合（RRF - Reciprocal Rank Fusion）算法进行重排，以获取稳定、无偏且精确的混合 RAG 召回列表。

## 涉及文件与修改范围
- [LongTermMemoryPlugin.ts](file:///d:/Projects/MyAgent/src/core/usecases/LongTermMemoryPlugin.ts)
  - 引入 RRF 混合重排融合算法。
  - 在 `BeforeModel` 生命周期钩子中，分双路执行匹配：
    - **向量路**：通过 Embedding 获取 1536 维特征向量，检索向量库获得相似度 $\ge 0.5$ 的 Top-N 结果。
    - **关键字路**：利用正则在自然语言中提纯三大类高优技术标识符（反引号包裹文本、大写驼峰词、技术后缀文件名），直接在长期记忆物理切片中做 `includes` 降序召回。
  - 利用 RRF 计算加权分值并去重合并，筛选最终的前 5 条高相关事实片段并拦截注入。

## 验证与验收方案
- **单元测试**：针对 RRF 排位算法以及正则表达式多级级联提取的精度编写覆盖用例，保证虚词被拦截而关键标识符 100% 捕获。
- **集成测试**：模拟用户包含精准文件标识符（例如“告诉我是如何通过 `session.ts` 中的 `rebuildVectorDbIfEmpty` 拦截判断的”）的 Query 问询，验证物理检索优先召回了相关的 facts并成功注入 System Prompt。
- **规范质检**：编译与 ESLint 必须 100% 成功通过。
