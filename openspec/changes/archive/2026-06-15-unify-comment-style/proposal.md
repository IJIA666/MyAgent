## 改造原因

当前项目（IJIA Agent）中，TypeScript 源代码的文档注释风格不够统一，部分注释中混杂了 JSDoc 传统的类型声明（如 `@param {string} sessionId` 或 `@param sessionId 可选的会话标识` 中夹带冗余类型描述），同时部分公开 API 缺少必要的参数与返回值说明。这导致在 TypeScript 下产生了类型冗余，并削弱了 IDE 的自动悬浮提示体验。

为了规范化代码文档体系，并移除不必要的冗余，有必要引入并统一使用标准的 TSDoc 规范，使 IDE 悬浮提示与文档生成更加清晰高效。

## 变更内容

1. **统一 TSDoc 规范**：对所有导出的 Class、Interface、Method、Function 统一使用 TSDoc 风格。
2. **消除冗余类型**：移除注释中所有的 `{type}` 语法（如 `{string}`、`{number}`），仅保留描述本身，将类型交由 TypeScript 编译器表达。
3. **规范参数与返回值描述**：使用标准的 `@param name - 描述`（带连字符 `-`）和 `@returns 描述` 语法。
4. **规范行内注释**：复杂的内部实现逻辑分步骤使用 `//` 进行单行描述。

## 影响范围

1. **受影响代码**：项目 `src` 目录下的所有 TypeScript 源代码文件，包括但不限于初始化模块、核心 Brain 模块、Action 模块等。
2. **API 与运行时**：本次变更仅涉及代码注释的优化，不涉及任何对外 API 的签名改变及运行时行为变更。
