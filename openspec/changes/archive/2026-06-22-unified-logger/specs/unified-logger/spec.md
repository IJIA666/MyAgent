## 新增需求

### 需求: 统一诊断日志记录与分级输出

系统必须提供全局统一的诊断日志记录模块（ Logger ），支持 `DEBUG` 、 `INFO` 、 `WARN` 、 `ERROR` 四个日志级别，实现控制台彩色输出与日志文件安全追加落盘，并支持基于环境变量和文件的分级过滤。

#### 场景: 诊断日志的分级控制与落盘行为
- **WHEN** 系统启动且未运行在单元测试环境中时
- **THEN** 诊断日志模块必须初始化。控制台输出（ ConsoleSink ）默认仅展示 `INFO` 及以上级别的彩色格式化日志；落盘文件输出（ RotatingFileSink ）必须将日志全量（含 `DEBUG` 级）异步安全写入 `.myagent/run.log` 文件。

#### 场景: 日志大小与数量轮转控制
- **WHEN** 日志文件 `.myagent/run.log` 的大小达到或超过 `10MB`（ 即 10 * 1024 * 1024 字节 ）时
- **THEN** 系统必须自动触发日志文件轮转，保留最多 5 个历史日志备份文件（ 即 `run.log.1` 至 `run.log.5` ），避免磁盘空间无限制膨胀。

#### 场景: 终端环境变量动态级别控制
- **WHEN** 启动系统时传入了环境变量 `LOG_LEVEL` （ 如 `LOG_LEVEL=debug` ）
- **THEN** 控制台输出（ ConsoleSink ）的最低展示级别必须调整为该环境变量指定的级别。


### 需求: Immer 变更补丁的大文本摘要压缩

系统在记录 `[Plugin Trace]` 诊断日志时，必须对 Immer 变更补丁（ Patches ）中产生的大文本内容进行 Map 摘要压缩，并且将该 trace 日志级别定为 `DEBUG` 级，以防止终端产生海量信息噪音。

#### 场景: Immer 变更日志的文本截断压缩与降级展示
- **WHEN** 系统在 Hook 中件间管道执行完毕产生 Immer 变更补丁（ Patches ），且 patches 数组长度大于 0 时
- **THEN** 系统必须对 patches 数组中的每一项 value 进行压缩：若 value 为字符串类型且长度超过 100 字符，则在日志中将其替换为 `"[String: X chars]"`（ X 为原字符串长度 ）；若 value 为数组类型，则替换为 `"[Array: X items]"` ；处理后的日志以 `DEBUG` 级别发出。


### 需求: 单元测试环境日志静音

系统在 Vitest 单元测试运行期间，必须自动切换到静音模式，防止大量的单元测试诊断日志向终端倾泻或产生无意义的文件写入。

#### 场景: 单元测试运行下的日志静音行为
- **WHEN** 系统检测到 `process.env.VITEST === "true"` 且未配置环境变量 `MYAGENT_TEST_LOG=1` 时
- **THEN** 诊断日志模块必须自动配置空的 `sinks` 数组（ 或空的 `loggers` 列表 ），关闭所有控制台和文件的写入输出，实现物理屏蔽静音。


### 需求: 进程非正常退出时的刷盘防丢失防护

系统在进程收到中断信号被强制终止时，必须能捕获事件并异步调用强制刷盘销毁（ dispose ），确保缓存在内存中的最后一批诊断日志不丢失。

#### 场景: 进程退出信号触发的日志强制写盘
- **WHEN** 操作系统收到 `SIGINT` 或 `SIGTERM` 异步退出信号时
- **THEN** 系统必须在应用完全退出前，挂载并等待异步执行 LogTape 的 `await dispose()` 接口，强制刷盘所有缓冲区内的残存数据，确认完成后再调用进程退出；若直接触发同步 `exit` 事件，则仅执行同步重置兜底。
