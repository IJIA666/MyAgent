## 新增需求

### Requirement: 管道异步执行稳定性与并发锁机制

智能体底座的生命周期 Hook 管道运行调度器必须能够安全地承载异步中间件流程，并在流转期间为会话状态提供并发冲突保护和异常熔断隔离。

#### Scenario: 异步中间件在执行挂起时安全运行且不发生崩溃
- **WHEN** 智能体触发 Hook 生命周期，且中间件在执行期间遇到 `await` 异步微任务挂起（如人机协同审批等待）时
- **THEN** 运行调度器必须通过托管 Draft 的方式确保代理 Proxy 沙箱在整个异步生命周期内长期有效，严禁提前被撤销，且允许在异步分发完成后顺利生成 Patch 变更并落盘

#### Scenario: 管道异步执行期间外部并发修改被拦截
- **WHEN** 智能体的洋葱生命周期管道正在异步执行，且外部定时任务或其他非洋葱圈内的并发写操作试图直接修改宿主 Session 状态时
- **THEN** 宿主 SessionContext 必须通过忙状态锁立即拦截该写操作并抛出并发修改异常，确保洋葱圈管道状态的封闭性与数据一致性

#### Scenario: 管道执行流转异常安全熔断
- **WHEN** 管道在执行中间件或等待审批时发生超时、拒绝审批或运行异常时
- **THEN** 运行调度器必须捕获异常并熔断流转，直接废弃该沙箱 Draft 绝不向宿主落盘任何残缺的状态，同时确保在 `finally` 中将宿主 SessionContext 的忙状态锁安全释放
