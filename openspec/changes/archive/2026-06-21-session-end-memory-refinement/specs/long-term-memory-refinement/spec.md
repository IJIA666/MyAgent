## 新增需求

### 需求: 异步提炼对话记忆并落盘
系统在当前会话结束时，必须异步且非阻塞地调用大模型（ LLM ）提取当前会话中沉淀出的事实、经验与偏好知识，并增量追加写入到项目 `.agent/` 目录下的长期记忆文件 `.agent/MEMORY.md` 中。

#### 场景: 对话正常结束触发异步记忆自省
- **WHEN** 大模型当前轮次工具执行完毕，会话自然结束（触发 `SessionEnd` 钩子）
- **THEN** 系统自动在后台发起异步非阻塞任务，获取最近几轮对话历史并发送给大模型进行自省，最终把提炼后的事实增量追加写入到 `.agent/MEMORY.md` 中，在此期间不得阻塞用户的任何交互或主对话循环。

### 需求: 自省提炼的阈值与节流控制
系统在触发异步提炼前，必须对本次会话的对话历史和内容进行量化评估，只有当对话内容达到设定的最低复杂度或更新阈值时，才触发大模型记忆提炼请求，以规避不必要的 Token 消耗。

#### 场景: 对话内容过少时跳过自省提炼
- **WHEN** 触发 `SessionEnd` 钩子，但本次会话的有效对话历史少于 2 轮
- **THEN** 系统直接终止本次提炼任务，不向大模型发起提炼请求。

### 需求: 推理启动时动态注入长期记忆
系统在每次大模型对话推理启动前，如果检测到项目 `.agent/` 目录下存在持久化的长期记忆文件 `.agent/MEMORY.md` ，必须读取其内容（限制最大读取长度为最新 4000 字符），将其动态追加并整合到大模型当前 System Prompt 的末尾。

#### 场景: 大模型推理前加载并注入记忆文件
- **WHEN** 大模型即将开始新一轮推理生成（触发 `BeforeModel` 钩子）且检测到 `.agent/MEMORY.md`
- **THEN** 系统读取该文件内容（最多读取最新 4000 字符），格式化包装为长期上下文片段，动态追加到当前大模型请求的首个 system 消息的 content 末尾（优先追加到首个 system 消息末尾；若不存在则在数组首部新增一条），以实现记忆召回。
