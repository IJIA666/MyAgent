## MODIFIED Requirements

### Requirement: 逻辑学习轨迹必须包含触发任务的用户输入

系统 MUST 由用户任务入口显式确定逻辑学习边界，并用该边界判断当前 run 是否有资格推进 Skill 学习计数或安排后台复盘。达到复盘阈值时，系统 MUST 在 `RunEnd` 冻结主会话截至 `historyEndIndex` 的完整当前对话消息历史，并以原生消息结构交给后台 Review；该快照 MUST 剥离父会话 system 消息，MUST 包含当前历史中更早任务的 user/assistant/tool 消息和触发任务的最终回复，MUST NOT 以逻辑学习边界作为复盘输入起点。系统 MUST NOT 通过索引减一或反向搜索角色猜测逻辑学习边界，也 MUST NOT 使用固定消息条数或逐消息字符上限二次裁剪复盘快照。前台已压缩的历史摘要视为当前上下文，系统不要求恢复压缩前的原始消息。统一模型预算机制 MAY 在实际后台模型请求超出目标模型预算时压缩隔离副本，但 MUST NOT 修改排队快照或父会话历史。

#### Scenario: 正常用户任务完成

- **WHEN** 用户提交一条消息，主 Agent 完成若干模型循环并返回最终回复，且累计值达到复盘阈值
- **THEN** 系统冻结从当前会话第一条非 system 消息到本次 `historyEndIndex` 的对话快照
- **THEN** 触发任务的用户消息、助手消息、工具调用、工具结果和最终回复按当前历史顺序保留

#### Scenario: 当前任务之前已有历史

- **WHEN** 会话已有多个已完成任务，用户又提交一个达到复盘条件的新任务
- **THEN** 复盘快照包含当前会话中更早任务和新任务的消息
- **THEN** 系统不得因为更早任务已经贡献过计数或参与过复盘而将其从当前快照排除

#### Scenario: 后续复盘重复看到此前上下文

- **GIVEN** 任务 A 完成后曾触发一次后台复盘，且其消息仍在主会话当前历史中
- **WHEN** 后续任务 C 完成并再次达到复盘阈值
- **THEN** 任务 C 的复盘快照仍包含任务 A 及二者之间的当前会话历史
- **THEN** 系统不维护或应用“已复盘消息”游标来裁掉这些消息

#### Scenario: 等待用户交互后恢复完成

- **GIVEN** 当前逻辑任务因交互工具暂停并保存了学习延续状态
- **WHEN** 用户回答后任务恢复、最终完成并达到复盘阈值
- **THEN** 复盘快照从恢复后的主会话当前历史一次性取得
- **THEN** 最初用户任务、等待前消息、交互工具回答、恢复后消息和最终回复按发生顺序各出现一次

#### Scenario: 当前历史已经由前台压缩

- **GIVEN** 主会话在触发复盘前已经把较早消息压缩为当前历史中的摘要消息
- **WHEN** 后续任务达到复盘阈值
- **THEN** 后台复盘收到该摘要消息和其后的完整当前消息
- **THEN** 系统不恢复或拼接已经不属于主会话当前历史的压缩前原文

#### Scenario: 后台原生回放当前上下文

- **WHEN** 主会话当前历史包含 system、user、assistant 和 tool 消息，调度器接受本次复盘请求
- **THEN** 复盘快照剥离父 system，隔离 Review Agent 使用自身 system，并按原角色和工具关联字段回放 user、assistant 和 tool 消息
- **THEN** 隔离 Review Agent 在回放消息末尾追加复盘 user 指令
- **THEN** 系统不得把整段会话嵌套成单条 JSON 轨迹消息后再交给模型

#### Scenario: 后台请求超过统一模型预算

- **GIVEN** 调度器已经接受并保存完整的非 system 对话快照
- **WHEN** 隔离 Review Agent 的实际请求超过当前模型预算
- **THEN** 统一模型预算机制可以只压缩隔离副本，并以摘要化材料继续复盘
- **THEN** 排队快照和父会话历史保持不变，系统不得退回固定消息条数或逐消息字符裁剪

#### Scenario: 内部生成没有用户任务边界

- **WHEN** 系统启动一次不属于用户任务或交互恢复的内部生成，且没有提供合法逻辑学习边界
- **THEN** 该运行不得推进 Skill 学习计数或安排后台复盘
- **THEN** 系统记录去敏的 `missing_learning_boundary` 诊断

#### Scenario: 逻辑学习边界索引越界

- **WHEN** RunEnd 收到的逻辑学习边界小于零、大于结束索引或超出当前历史
- **THEN** 系统 fail-closed 丢弃本次学习证据
- **THEN** 系统不得通过修正、减一或角色搜索继续复盘
