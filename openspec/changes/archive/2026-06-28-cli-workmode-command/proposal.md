## 改造原因

智能体目前已实现了动态工作安全模式（YOLO / Auto / Safe / Plan）下的气泡注入和敏感工具物理阻断，但当前的控制台交互（CLI）层缺乏实时修改或查询此安全状态的指令。用户如需切换模式进行开发测试，必须物理修改环境变量并重启程序，严重影响了调试敏捷性。
此外，当前 `/help` 菜单硬编码的 `/model <id>` 提示不够精确，隐藏了“不输入参数会自动唤起 Clack 交互式配置向导”这一极佳的体验细节。我们需要彻底补齐和校正这些命令层的不同步问题。

## 变更内容

1. **新增 `/workmode` 命令**：添加一个斜杠指令，支持在空参时查看当前工作模式，以及传入 `Safe` / `Auto` / `YOLO` / `Plan` 参数来同步热修改 `SessionContext` 的私有状态和底层工具链的全局校验模式。
2. **可视化图形菜单整合**：在控制台双击 `/` 唤起的 Clack 快捷操作列表里增加工作模式切换条目，并与路由分发器无缝衔接。
3. **帮助菜单与参数修正同步**：在 `/help` 命令打印列表中补充新指令，并将原 `/model <id>` 指正为非必填的可选参数提示 `/model [id]`。

## 业务能力

### 新增业务能力
- `cli-workmode-command`: 动态切换智能体执行安全模式的命令行（CLI）指令及其与可视化图形菜单、帮助菜单的联动契约。

### 修改业务能力
- 无

## 影响范围

- **命令行实现层**：`src/adapters/input/interface/commands/` 目录。
- **命令注册与分发层**：`src/adapters/input/interface/command.ts` 及其命令导出入口 `index.ts`。
- **帮助信息渲染层**：`src/adapters/input/interface/commands/help.ts`。
