## 背景

当前工作区 `d:\projects\MyAgent` 处于全新初始化状态，无任何业务代码及配置。为了安全地在该工作区中提供大语言模型与本地文件系统的交互能力，必须设计并实现一套具备极高透明度、零框架黑盒、且带有物理级路径防护沙箱的 TypeScript Agent 命令行运行程序。

## 目标与非目标

**目标:**
- 建立基于 TypeScript 及 Node.js 的极简项目脚手架，引入 `tsx` 作为免编译直接运行的时环境。
- 实现完全基于原生 `openai` SDK 的会话管理器，完美支持多轮对话上下文追踪，并动态解析大模型通过最新的 **Tools 工具调用协议 (`type: "function"`)** 返回的函数签名。
- 实现高度受控的本地文件操作 Tools（包括 `readFile`, `writeFile`, `listFiles`），并在本地运行前应用绝对路径规范化比对，确保 Agent 绝不能在越界路径中执行任何读写。
- 实现基于 Node.js `readline` 的极简交互式终端 CLI（REPL 循环）。
- 支持通过 `.env` 文件动态切换大模型服务商端点、API Key 与所调用的 DeepSeek 模型。

**非目标:**
- 本项目不构建任何 Web UI 或复杂的图形界面，所有交互完全基于命令行 REPL 进行。
- 坚决不向大模型暴露任意终端命令执行工具（如 Shell 命令行工具），仅暴露具备沙箱阻断功能的受限文件工具，以绝对防范命令注入与数据损毁风险。

## 架构决策

- **架构决策一：选用官方原生 `openai` Node.js SDK**
  - **理由**：由于 DeepSeek 官方 API 提供了与 OpenAI 100% 兼容的接口协议，直接使用官方 `openai` 包是阻力最小、网络吞吐最纯正、生态最健壮的方案，能让我们直接与底层的 HTTP 请求和 Tools 解析进行打交道，没有任何第三方封装屏障，非常适合学习和深入开发。
  - **备选方案**：使用 LangChain.js 等重型 Agent 框架。由于它们包含了极多繁琐的封装与自动转换层，隐藏了 Tools 调用和上下文传递的本质逻辑，因此不予采用。

- **架构决策二：采用 TSX 运行时，取消传统的 TS 构建监听流**
  - **理由**：`tsx` 是基于 esbuild 构建的高速 TypeScript 运行时，能够直接通过 `npx tsx src/index.ts` 启动执行，自动加载 `.ts` 文件。这极大地简化了本地编译部署成本，避免了在开发简单 CLI 工具时需要配置复杂的 `tsconfig.json` 并频繁运行 `tsc` 的烦恼。
  - **备选方案**：使用传统 `tsc --watch` 生成 `dist/*.js` 目录并用 `node` 执行，这增加了文件垃圾和无谓的构建监听开销。

- **架构决策三：基于 `path.resolve` 与前缀比对的物理级路径沙箱设计**
  - **理由**：为防止 Agent 被用户恶意诱导或自身推理失误尝试篡改系统盘文件，在文件系统相关 Tools 函数中，对模型传入的路径首先调用 `path.resolve(workspacePath, targetPath)` 进行物理级绝对路径解析（这能直接消除一切 `../` 的穿透绕过）；然后通过 `resolvedPath.startsWith(resolvedWorkspaceRoot)` 进行前缀匹配。若返回 `false`，则说明该路径试图跨越授权工作区，在工具层直接截断执行，保障本地系统安全。
  - **备选方案**：使用简单的正则表达式拦截 `..`，该方式容易在多重目录嵌套或操作系统软链接场景下发生绕过，安全性低下。

- **架构决策四：使用原生的 `readline` 实现控制台交互 REPL**
  - **理由**：Node.js 原生的 `readline` 模块极其稳定轻便，且能极为自然地支持 `readline.question` 异步对话循环。我们可以通过精细控制控制台标准输出的流回显（stdout.write），实现类似打字机与思考进度的渐进回显。
  - **备选方案**：使用第三方终端 TUI 库（如 Ink 或 Blessed）。虽然界面华丽，但引入了大量平台兼容风险与极其复杂的重构成本，违背了极简 Agent 核心逻辑的学习目标。

## 风险与权衡

- **[Risk] DeepSeek API 并发限制与超时** → **Mitigation**: 每一个 API 交互请求均被包裹在带有超时机制与精美错误重试/友好回显的 `try-catch` 块中。
- **[Risk] 意外泄露 DeepSeek API Key** → **Mitigation**: 将 `.env` 自动添加到本项目的 `.gitignore` 中，仅提供 `.env.example` 供用户复制配置。
