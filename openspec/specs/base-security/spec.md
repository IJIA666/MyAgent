## 新增需求

### 需求: 物理路径去模糊与防逃逸
智能体在处理所有高层文件 API 操作（读取、写入、修改、列目录）以及终端工作目录（cwd）时，必须（MUST）对目标路径调用 `fs.realpathSync` 物理绝对路径解析，并强制（SHALL）要求其位于标准化后的工作区物理绝对路径边界内。

#### 场景: 工作区内正常读写
- **WHEN** 智能体试图读取工作区内的相对路径文件 `./package.json`
- **THEN** 路径校验器校验成功，将路径解析为对应的真实物理绝对路径，并允许文件操作执行。

#### 场景: 软链接沙箱逃逸拦截
- **WHEN** 工作区内存在一个符号链接 `./link_to_system` 指向外部 `C:\Windows`，智能体试图读取 `./link_to_system/system.ini`
- **THEN** 路径校验器通过 `fs.realpathSync` 展开发现真实物理路径为 `C:\Windows\system.ini`，判定其溢出安全边界，抛出拒绝访问的错误强行拦截。

### 需求: 终端写倾向命令拦截与安全降级
在终端命令 `execute_command` 拦截过程中，系统必须（MUST）通过敏感命令及常见别名正则审查输入命令。除了明确安全的只读白名单指令（如 `git status`、`git diff`）外，凡是包含写倾向、管道混写或未识别的复杂脚本，系统应当（SHALL）将其安全级别降级为 `behavior: 'ask'` 并挂起执行，拉起交互弹窗提问，不得静默放行。

#### 场景: 只读命令静默放行
- **WHEN** 智能体试图在终端执行只读白名单内的命令 `git status`
- **THEN** 拦截器识别其为无风险只读指令，直接静默放行，无需用户审批。

#### 场景: 危险写倾向命令降级审批
- **WHEN** 智能体试图在终端执行具有写倾向的删除命令 `Remove-Item -Force d:\Projects\MyAgent\dist`
- **THEN** 拦截器触发敏感命令正则与非只读判定，自动挂起命令执行，将命令的完整内容通过 `Ask` 机制展示，等待用户裁决。

### 需求: 动态路径越界 Ask 授权
当智能体试图访问工作区外的目录或文件（如读取或写入外部配置文件），路径验证器应当（SHALL）挂起当前操作并调用 `Ask` 服务进行提问；若用户授权，则将该物理绝对路径临时追加到内存的 Session 读写白名单中，并在当前会话中允许此次及后续的相同越界操作。

#### 场景: 越界读取 Ask 确认后放行
- **WHEN** 智能体试图读取宿主机上的 `C:\Users\admin\.gitconfig`，路径验证器触发越界。
- **THEN** system 挂起读取，向用户发出授权询问；当用户允许后，系统将此路径加入临时只读白名单，并顺利返回文件读取结果。
