# test-directory-isomorphism

## Purpose
本模块负责系统测试目录同构及物理目录结构的规范保障，消除测试与源文件对应的物理嵌套路径不一致和套娃命名嵌套，并在代码重构物理迁移过程中，确保系统的各项单元测试用例全部绿灯运行通过。

## Requirements

### Requirement: 测试目录同构与路径一致性规范
非集成/非构建相关的单元测试代码物理路径必须与其关联的源文件物理路径保持 1:1 同构对齐，且原生工具适配器的实现目录不能发生 tools/tools 等套娃命名嵌套。

#### Scenario: 目录同构与去套娃验证
- **WHEN** 检查项目物理目录结构时
- **THEN** 发现所有单元测试物理文件均存放于 `test/core/usecases/<子域>/` 或 `test/adapters/<子域>/` 下，且原生工具实现目录存放于 `src/adapters/tools/impl/`

### Requirement: 重构后单元测试绿灯保障
本变更的重构改动不得对系统既有业务行为引入任何回归缺陷，且重构带来的路径调整必须保证全量单元测试执行通过。

#### Scenario: 运行单元测试验证
- **WHEN** 终端执行并完成 `npm test` 命令时
- **THEN** Vitest 应成功运行所有的测试文件，所有测试用例必须 100% 通过且无 ESM 相对路径解析报错
