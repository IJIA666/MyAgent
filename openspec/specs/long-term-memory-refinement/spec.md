## 新增需求

### 需求: 异步提炼对话记忆并落盘
系统在当前会话结束时，必须异步且非阻塞地调用大模型（ LLM ）提取当前会话中沉淀出的事实、经验与偏好知识，并增量追加写入到项目 `.agent/` 目录下的长期记忆文件 `.agent/MEMORY.md` 中。

#### 场景: 对话正常结束触发异步记忆自省
- **WHEN** 大模型当前轮次工具执行完毕，会话自然结束（触发 `SessionEnd` 钩子）
- **THEN** 系统自动在后台发起异步非阻塞任务，获取最近几轮对话历史并发送给大模型进行自省，最终把提炼后的事实增量追加写入到 `.agent/MEMORY.md` 中，在此期间不得阻塞用户的任何交互或主对话循环。

### 需求: 自省提炼的阈值与节流控制
系统在触发异步提炼前，必须对本次会话的对话历史和内容进行量化评估，只有当对话内容达到设定的最低复杂度或更新阈值时，才触发大模型记忆提炼请求，以规避不必要的 Token 消耗。

#### 场景: 对话内容过少时跳过自省提炼
- **WHEN** 触发 `SessionEnd` 钩子，但本次会话的有效对话历史少于 2 轮
- **THEN** 系统直接终止本次提炼任务，不向大模型发起提炼请求。

### 需求: 推理启动时动态注入长期记忆
系统在每次大模型对话推理启动前，如果检测到向量数据库和项目 `.agent/` 目录下存在持久化的长期记忆，必须根据用户当前的 Query 向量进行检索查询，召回最相似的 Top-K 条记忆片段，将其动态追加并整合到大模型当前 System Prompt 的末尾以提供精准的上下文关联。

#### 场景: 大模型推理前进行向量相似度检索并注入记忆
- **WHEN** 大模型即将开始新一轮推理生成（触发 `BeforeModel` 钩子）且存在持久化的记忆数据库
- **THEN** 系统获取用户当前轮次输入的文本内容（截取前最多 2000 字符），生成其 Embedding 向量，并调用向量数据库的检索接口，匹配出相似度分值符合阈值（如相似度分值 >= 0.5）的 Top-K 条（如最多 5 条）记忆片段，将其格式化拼接，追加到当前大模型请求的首个 system 消息的 content 末尾（若不存在则在首部新建 system 消息），完成语义检索记忆召回。

### 需求: 事件/回调解耦式子智能体自省提炼
系统在触发异步记忆提炼时， 必须由生命周期插件将历史对话抛出， 并由宿主协调层启动一个搭载极简只读/特化写工具集的 Forked AgentLoop 实例来承接该自省任务。 子智能体将在独立的沙箱上下文环境中以 ReAct 模式运转以完成提炼并安全落盘。

#### 场景: 插件抛出事件后由 Session 协调层派生子智能体提炼
- **WHEN** 会话结束钩子触发， 且插件过滤判定消息复杂度满足自省阈值
- **THEN** 插件通过回调函数将历史消息向上传递， 宿主 `SessionManager` 在后台异步任务中承接该回调， 为提炼任务实例化一个隔离的 Forked Agent 实例， 该实例拥有独立的 `SessionContext` 与专属只读/写工具， 并运行 ReAct 推理， 自动判断调用写工具， 完成后销毁实例。

### 需求: 专属写记忆工具的安全路径锁定
供 Forked 子智能体调用的 `writeMemoryFile` 工具， 必须在底层强制限定写入文件的目标路径为 `.agent/MEMORY.md`， 不接受 any 外部路径参数传入， 严禁越权修改工作区其它文件。同时系统必须在写入物理文件后，自动对追加的内容发起异步切片并将其存入向量数据库，以保持向量索引与物理文件同步。

#### 场景: 提炼子智能体调用工具安全落盘并同步向量数据库
- **WHEN** 提炼子智能体在 ReAct 循环中发出 `writeMemoryFile` 调用
- **THEN** 工具读取传入的内容， 强制且唯一地追加写入至 `.agent/MEMORY.md` 文件中， 并且系统自动在后台异步对该新增的记忆内容按行/要点列表进行拆分切片，生成其 Embedding 向量并同步 upsert 追加写入向量数据库中，保持数据状态同步。

#### 场景: 规避 PostRunHook 高昂规范化质检开销
- **WHEN** 提炼子智能体调用 `writeMemoryFile` 追加写入记忆
- **THEN** 该工具必须显式标记其 `securityCategory` 为 `'safe'`（ 或 `'read'` ）， 从而不触发 `AgentLoop` 中针对代码写操作 `'write'` 的 `PostRunHook` 全量编译与 `eslint` 质检拦截， 规避额外的 CPU 损耗与环境缺失风险。
