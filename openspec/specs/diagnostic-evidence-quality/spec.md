# diagnostic-evidence-quality

## Purpose

建立诊断类回答中证据等级与结论强度的对应约束，防止模型将目录枚举或存在性检查夸大为真实测量结论，确保回答中的宣称范围与可追溯的依据严格匹配。

## Requirements

### Requirement: 诊断证据分级

系统必须（MUST）以接入真实工具结算路径的对象级证据账本区分 `presence`、`enumeration`、`measured` 与 `error`。每条记录必须绑定目标、指标、值、单位、来源、调用关联、覆盖范围和完整性。回合级摘要只能从相关记录派生，不得作为覆盖全部对象的事实源。

#### Scenario: 工具结算产生对象级记录

- **WHEN** AgentLoop 结算一个诊断相关工具结果
- **THEN** 系统必须调用该工具注册的证据解释器并把记录写入当前账本，而不是仅更新一个全局等级字符串

#### Scenario: 枚举只能形成候选

- **WHEN** 工具只返回对象列表而没有指标测量
- **THEN** 系统只能记录 enumeration，并把对象描述为候选

#### Scenario: 完整测量绑定目标与指标

- **WHEN** 工具返回明确目标的完整数量型指标
- **THEN** 系统必须记录 complete measured 及来源关联，且该记录只能支撑同一目标和指标的结论

#### Scenario: 部分结果形成下界证据

- **WHEN** 工具因权限、预算、链接边界、截断或取消仅覆盖部分目标
- **THEN** 系统必须记录 partial 或 lower-bound 及未覆盖原因

#### Scenario: 局部失败不得污染全局

- **WHEN** 某个目标查询失败但账本中存在其他目标的有效测量
- **THEN** 系统追加目标级 error 并保留其他记录，不得把整个回合永久覆盖为 error

#### Scenario: 自由文本数字不自动升级证据

- **WHEN** 未注册解释器的工具输出包含数字
- **THEN** 系统不得仅凭通用正则将其升级为 measured，必须保守记录为 presence 或 error

### Requirement: 结论声明与不确定性约束

系统必须（MUST）在最终回答提交前校验重要主张与对象级证据的对应关系。量化值、估算、完成度、主要原因、风险等级和可执行处置结论必须匹配相关目标、指标和覆盖范围；无匹配证据的内容必须删除或降级为未知项、候选项或待验证项。

#### Scenario: 无真实测量时禁止宣称完成

- **WHEN** 相关证据只有 presence 或 enumeration
- **THEN** 回答不得宣称深度分析完成、主要问题已确认或给出量化收益估算

#### Scenario: 完整测量只支持受限结论

- **WHEN** 某些对象拥有 complete measured
- **THEN** 回答可以仅针对这些对象给出量化结论，不得外推到未测量对象或整体范围

#### Scenario: 下界结果必须暴露不确定性

- **WHEN** 相关记录为 partial 或 lower-bound
- **THEN** 回答必须使用至少、已观察到或等价语义，并说明跳过、截断和未覆盖范围

#### Scenario: 无依据建议被降级

- **WHEN** 最终草稿包含没有相关证据的删除、迁移、优化或风险结论
- **THEN** 系统必须将其改写为待验证项并给出获取证据的具体条件，或从回答中移除

### Requirement: 导航和枚举错误不得升级为容量结论

系统必须（MUST）将浏览器导航结果、目录枚举结果和导航错误限制在其真实证据语义内。`ERR_ABORTED`、超时、拒绝或页面加载失败只能形成目标级 `error`，不得支持"目录过大"、占用空间规模或可释放容量等结论。

#### Scenario: 本地目录导航返回 ERR_ABORTED

- **WHEN** `browser_navigate` 访问本地目录时返回 `ERR_ABORTED`
- **THEN** 证据账本必须记录导航失败及目标，最终回答不得将其描述为目录过大或主要占用项

#### Scenario: 文件索引仅返回目录名称

- **WHEN** 浏览器文件索引或目录工具只返回若干文件和目录名称而没有字节指标
- **THEN** 系统最多记录 `enumeration`，不得记录 `measured` 或生成容量排序

#### Scenario: 已有其它目标的有效测量

- **WHEN** 一个导航目标失败，但账本中存在其它目标的完整容量测量
- **THEN** 系统必须保留其它测量，仅将失败目标标为未知，不得污染整个诊断回合
