## 新增需求

### 需求: 绝对静态系统提示词 (Absolute Static System Prompt)
系统提示词（System Prompt）的组装应当（SHALL）彻底剥离高频变化的动态参数（剥离 `<date>` 和 `<cwd>`，保留进程级静态常量 `<os>` 标签），使 System Prompt 在整个会话周期内保持物理字符内容绝对恒定，以确保大模型服务商的 Context Cache（上下文前缀缓存）命中率最大化。

#### 场景: 静态系统提示词生成
- **WHEN** 会话启动或触发上下文压缩重新构建系统提示词时
- **THEN** 系统提示词组装器被调用，返回的系统提示词内容中不包含任何动态的时间戳、当前路径或易变环境参数。

#### 场景: 会话内提示词恒定保全缓存
- **WHEN** 在多轮对话期间发生用户执行 `cd` 切换当前目录，或系统日期发生跨天跨周的变化时
- **THEN** 保存在消息历史第一项 (`messageHistory[0]`) 的系统提示词内容保持完全不变，其哈希值无变化，从而保全 Context Cache。
