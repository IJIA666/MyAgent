## 新增需求

### 需求: 虚拟磁盘盘符动态挂载与物理隔离 (Dynamic Disk Mounting and Isolation)
测试床必须提供 Windows 原生 `subst Z:` 盘符挂载能力，若盘符冲突则必须自动向下寻找可用空闲盘符进行挂载，并在测试结束后一键卸载（`subst <drive> /D`）以实现物理隔离。

#### 场景: 动态盘符挂载与卸载虚拟磁盘
- **WHEN** 测试周期启动时，脚本探测到 `Z:` 盘已被占用，降级选择空闲的 `Y:` 盘进行 `subst` 挂载，并在环境初始化完成后，测试结束后触发卸载
- **THEN** 智能体能在 `Y:\` 绝对路径下自如检索，且物理卸载后宿主机上不遗留 `Y:` 映射，原有的 `Z:` 盘不会受到 any 误伤

### 需求: ACL 权限拒绝壁垒模拟 (ACL Permission Denial Simulation)
测试床必须支持利用 Windows 内置 `icacls` 机制，强制剥夺当前用户对模拟的核心保留文件的写（W）与删除（D）权限，并在清理校验完毕后支持自动重置恢复权限，以考察智能体的强阻力清理与容错能力。

#### 场景: 核心文件拒绝访问阻力与权限还原
- **WHEN** 测试环境初始化时对模拟的核心文件配置 ACL 拒绝访问，而在环境销毁重置时进行 reset 还原
- **THEN** 智能体以 Force 参数删除时仍遭遇 Access Denied 报错并能优雅跳过，且 teardown 能顺利清除该文件

### 需求: 进程生命周期绑定的独占文件锁 (Lifecycle-Bound File Locking)
测试床必须以主测试进程的生命周期为锚点，以子进程形式独占锁定目标垃圾日志文件。一旦主进程生命周期终止，该文件锁定必须随之被操作系统内核自动强行释放，不得产生残留死锁的僵尸进程。

#### 场景: 锁定文件测试与防僵尸锁清理
- **WHEN** 初始化时以非分离（non-detached）模式派生子进程锁死文件，并且主控进程退出
- **THEN** 锁定子进程随主进程销迹而自动终结，垃圾文件的独占锁立即解除，避免阻碍下一次初始化部署

### 需求: 非侵入式工作区沙箱安全隔离 (Non-Intrusive Sandbox Redirection)
智能体必须支持在测试状态下，完全不修改自身安全校验源码、Prompt 逻辑和物理 `.env` 配置文件的前提下，通过一键评测启动器以子进程派生形式，在进程环境变量中动态重定向 `AUTHORIZED_WORKSPACE_DIR` 至虚拟挂载盘符上，对物理真实盘实现安全隔离。同时，该用于重定向的内部环境变量不应出现在对外的公开配置文件模板 `.env.example` 中，以保持用户配置界面的整洁纯净。

#### 场景: 配置重定向与物理越界防护审计
- **WHEN** 一键评测启动器派生启动智能体，并仅在子进程的环境中将 `AUTHORIZED_WORKSPACE_DIR` 配置为实际挂载的测试盘符（如 `Z:\`）
- **THEN** 智能体所感知的授权工作区边界即为虚拟磁盘根，网关在零修改情况下天然拦截一切跨出该虚拟盘范围的操作，确保物理宿主机的数据绝对安全，且物理配置文件 `.env` 中的原始配置与公开配置模板 `.env.example` 中均不包含该键值声明
