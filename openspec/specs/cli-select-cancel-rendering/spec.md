## 新增需求

### Requirement: CLI 单选菜单取消时不得展示删除线选项

系统在仓库内所有交互式单选菜单中必须（MUST）统一控制取消态渲染。用户按 `ESC` 或触发取消时，最终展示不得把当前焦点项渲染为删除线，也不得暗示该项已被选择或否决。

#### Scenario: 主菜单取消时仅展示取消结果

- **WHEN** 用户打开 `/` 主菜单后直接取消
- **THEN** 终端最终输出只应表达"本次操作已取消"，不得展示带删除线的焦点项文本

#### Scenario: WorkMode 菜单取消时不更改状态且不展示删除线

- **WHEN** 用户执行 `/workmode` 并在单选菜单中取消
- **THEN** 当前工作模式保持不变，且终端最终输出不得展示带删除线的菜单项

#### Scenario: 模型选择取消时不更改配置且不展示删除线

- **WHEN** 用户执行 `/model` 并在模型选择或 reasoning 选择中取消
- **THEN** 当前模型配置保持不变，且终端最终输出不得展示带删除线的菜单项
